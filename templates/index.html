API Reference

AllSeeingEye provides a REST API for programmatic access to all features.

POST /api/analyze
{
  "directory": "/path/to/project",
  "exclude_dirs": ["node_modules", "venv"],
  "exclude_files": ["*.pyc", "*.log"],
  "output_format": "json",
  "include_visualizations": true,
  "include_similarity": true
}

Response will contain the analysis results in the requested format.
